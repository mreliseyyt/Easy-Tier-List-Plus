## FEATURES 💡

### Basic (from original Akascape)
- Open Source and FREE
- Make custom categories / tiers
- Add images from file
- Import image directly from URL
- Full drag and drop support
- Easily arrange the content
- Customise colors and text
- Full screen mode
- Save the data as file and reuse

### New in the Mod (PLUS) ✨
- 🖼️ **Image captions** — add a caption to every image
- 🔍 **View image in full size** — double click to open in a separate window
- 📐 **Individual image size** — original or custom px
- 📋 **Paste from clipboard** — Ctrl+C in browser, Ctrl+V in app
- 💾 **`.tierlist` format** — entire tierlist in one file (images embedded as Base64)
- ↔️ **Horizontal scroll** — each category has its own scrollbar for many items
- 🖱️ **Drag by the image itself** — grab the picture and drop it into another tier
- 🗑️ **Delete items** — right-click or `Del` key
- 📸 **Export FULL tierlist** — snapshot of all categories at once, not just visible ones
- 🎚️ **Global image size slider** — resize all images at once
- 🔤 **Custom font** — family, size, bold, italic, underline
- 🎨 **Custom color scheme** — category background, main background, text color
- 🌐 **Two languages** — English / Русский (switch on the fly)

## Hotkeys ⌨️

| Key | Action |
|-----|--------|
| `Ctrl+S` | Save JSON |
| `Ctrl+O` | Open file |
| `F11` | Toggle fullscreen |
| `Esc` | Exit fullscreen |
| `Del` | Delete selected item |
| `RMB` | Context menu (delete, edit, size...) |
| `Double click` | View image in full size |

## File formats 📁

| Format | Description |
|--------|-------------|
| `.json` | Data only, images in a separate `_assets` folder |
| `.tierlist` | Single file: JSON + all images embedded as Base64 |
| `.png` | Screenshot of the whole tierlist (all categories) |

## How to Install? ⚙️

### For regular users (Windows)
1. Download the zip from **DOWNLOAD** section
2. Extract the archive
3. Run **`easy-tier-list-plus.exe`**

### For Python developers
1. Install dependencies:
```bash
pip install customtkinter CTkMenuBar CTkColorPicker CTkMessagebox tkinterdnd2 pillow
```
On Windows additionally:
```bash
pip install pywinstyles
```
2. Run:
```bash
python easy-tier-list-plus.py
```

### Build .exe with auto-py-to-exe
```bash
py -3.13 -m pip install auto-py-to-exe
py -3.13 -m auto_py_to_exe
```
Add to **Hidden Imports**:
```
customtkinter
CTkMenuBar
CTkColorPicker
CTkMessagebox
tkinterdnd2
PIL
PIL._tkinter_finder
pywinstyles
```
